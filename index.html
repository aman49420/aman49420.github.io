CafeAIOS

A multi-tenant subscription SaaS that runs a cafe's ordering, staff, payments and marketing, with one AI agent customers talk to on WhatsApp or by scanning the table QR.

Next.js · Prisma · WhatsApp Cloud API · Razorpay

One app. Every cafe. One AI that takes the order.

Customers scan the table QR or message the cafe on WhatsApp and order in Hindi, English or Hinglish. The agent builds the order, suggests one upsell, calls a waiter, sends the bill and takes payment.

Behind it, the owner, manager, chef and waiters each get their own app, a platform admin onboards and bills every cafe, and a nightly AI job tells each owner what to push tomorrow.

Engineering decisions

Tenant isolation by default

The current cafe lives in AsyncLocalStorage and the Prisma client injects its ID into every query. Forgetting the context throws an error instead of leaking another cafe's data.

Provider-agnostic LLM layer

One adapter with tool calling for Gemini, Groq, Anthropic, OpenAI, OpenRouter or a self-hosted model. If a model is retired it falls back to the next one automatically.

Nightly sales intelligence

Computes revenue, average order value, upsell rate, peak hours and attach rates, then writes an owner briefing, items to push and new upsell pairings.

WhatsApp win-back campaigns

Segments for inactive, birthday, VIP and new customers. Each message carries an AI-written personal line, and replies are attributed back to the campaign.

Billing and dunning

Razorpay invoices, a reminder before the period ends, a 7-day grace period, then dashboards pause. Table QR ordering never stops.

Safe integrations

Webhook signatures verified for WhatsApp and Razorpay, dry-run modes for testing, staff hand-off when the AI escalates, and Vitest unit tests.
